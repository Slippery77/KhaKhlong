# ค้าคล่อง (KhaKhlong) — Brand Guidelines (กระชับ)

## แนวคิด
**"ค คล่อง"** — ตัวอักษร **ค** แรกของชื่อ วาดเป็น **เส้นเดียวต่อเนื่อง** (monoline) ไม่มีรอยต่อ:
ขดตัวบนเหมือนคลื่นที่ม้วน หางล่างยกขึ้นไหลตามแรงน้ำ สื่อ "ค้าคล่อง" = การค้าที่ไหลลื่นไม่ติดขัด
(พ้องเสียงกับ "คลอง" — การค้าริมคลองไทย)

## สี
| บทบาท | HEX | ใช้ที่ไหน |
|---|---|---|
| Brand (Earth Brown) | `#8C6D58` | สัญลักษณ์, ปุ่มหลัก, hover `#7a5c45` |
| Ink (Dark Cocoa) | `#2D241E` | Wordmark ไทย, ข้อความหลัก |
| Canvas (Warm Cream) | `#FAF7F2` | พื้นหลัง, icon-bg ของ app icon |
| Reverse | `#FFFFFF` | บนพื้นเข้ม (เส้นบางลง ~8% ชดเชยแสง) |

## Typography
- Wordmark: **Kanit** SemiBold (ค้าคล่อง) + Regular (KhaKhlong, letter-spacing ~6) — licence OFL ใช้เชิงพาณิชย์ได้
- ไฟล์ lockup ที่ส่งมอบแปลงเป็น **outlined path แล้ว** (ไม่พึ่งฟอนต์บนเครื่อง)
- UI ทั้งระบบ: Kanit เหมือนเดิม

## รูปแบบที่อนุญาต
1. **Symbol สีแบรนด์** — บนพื้นครีม/ขาว (`#FAF7F2`, `#FFFFFF`)
2. **Symbol white/reverse** — บนพื้นน้ำตาลเข้ม/ดำ/ภาพถ่าย
3. **Symbol สีเดียว (mono)** — พิมพ์ 1 สี ตราประทับ ใบเสร็จ
4. **Lockup แนวนอน** — หน้า login, header, เอกสาร
5. **Lockup ตั้ง** — ป้ายหน้าร้าน, โซเชียล, ช่องว่างแคบ
6. **Small-size cut** (`a-symbol-small.svg`, เส้นหนาขึ้น) — สำหรับ ≤32px เท่านั้น

## พื้นที่ว่างและขนาด
- Clear space: อย่างน้อย **1 เท่าของความหนาเส้น** รอบสัญลักษณ์
- ขนาดเล็กสุด: สัญลักษณ์ปกติ 24px / small-size cut 16px / lockup 120px กว้าง

## ห้ามทำ
- ❌ เปลี่ยนสีนอกเหนือจากตารางด้านบน / เพิ่ม gradient เงา
- ❌ ยืดบิด หมุน เพิ่มมุมโค้งเอง
- ❌ วางบนพื้นลายตาโดยไม่มี backing
- ❌ ใช้ lockup (มีตัวหนังสือ) ที่ขนาดเล็กกว่า 120px — ใช้สัญลักษณ์เดี่ยวแทน
- ❌ แยกเส้นออกจากกัน (เอกลักษณ์คือเส้นเดียวต่อเนื่อง)

## ไฟล์
ดู `logo/` ในโฟลเดอร์โปรเจกต์: `a-symbol-*.svg` (สัญลักษณ์ทุกเวอร์ชัน),
`a-lockup-*.svg`, `favicon.ico` + PNG ทุกขนาด, `site.webmanifest` + `head-snippet.html`

## หมายเหตุ
- ทดสอบแล้ว: audit ผ่าน (99/100 symbol), anchors 5 จุด, สีเดียว ไม่มี gradient/filter
- แนะนำให้ค้นtrademark databases ก่อนจดทะเบียนจริง (โลโก้นี้ออกแบบใหม่ แต่ไม่รับประกันความว่างของฐานข้อมูล)
