## 1. เตรียมเครื่อง

### 1.1 dev หรือ preview — ใช้อันไหนทดสอบอะไร

| | `npm run dev` | `npm run build` + `npm run preview` |
|---|---|---|
| service worker | **ไม่มี** (`devOptions.enabled: false`) | มี |
| ใช้ทดสอบ | snapshot, ป้าย, outbox, หน้าต่าง, บล็อก logout/ปิดกะ | ทุกอย่าง + เปิดแอปตอนออฟไลน์ (reload) + UpdatePrompt + ติดตั้งแอป |
| แก้โค้ดแล้ว | เห็นทันที | **ต้อง build ใหม่ทุกครั้ง** ไม่งั้นได้เวอร์ชันเก่า (สาเหตุที่เคยหลงมา 2 รอบ) |

**แนะนำ**: พัฒนาด้วย dev · ทดสอบรอบสุดท้าย/ซ้อมเดโมด้วย preview

### 1.2 วิธีจำลองออฟไลน์ — 2 แบบ ผลต่างกัน

| วิธี | ทำยังไง | ป้ายที่ควรเห็น | ทดสอบอะไร |
|---|---|---|---|
| **A. ปิด backend** | Ctrl+C ที่ terminal ของ backend | "ติดต่อเซิร์ฟเวอร์ไม่ได้" (มีปุ่ม ⟳) | server ล่ม / เน็ตร้านเข้าได้แต่ server ไม่ตอบ — **ใช้บ่อยที่สุด** |
| **B. DevTools Offline** | F12 → Network → Throttling → Offline | "ออฟไลน์" (ไม่มีปุ่ม ⟳) | เน็ตหลุดทั้งเครื่อง |

> ปิด Wi-Fi **ไม่ได้ผล** — frontend กับ backend อยู่ `localhost` เครื่องเดียวกัน ไม่ผ่านเน็ต
> วิธี B กับ preview: ต้องติ๊ก Offline **หลัง** หน้าโหลดเสร็จ ไม่งั้น reload แรกไม่มี service worker คุม

### 1.3 เครื่องมือดูข้างใน

- **IndexedDB**: F12 → Application → IndexedDB → `pwa-pos` → `snapshots` / `outbox` (กดปุ่ม ⟳ ในแผงเพื่อรีเฟรช — ไม่อัปเดตเอง)
- **Service worker**: Application → Service workers (ดู status, ปุ่ม Unregister, ติ๊ก Update on reload)
- **ล้างทุกอย่าง** (เริ่มใหม่สะอาด): Application → Storage → Clear site data

### 1.4 สคริปต์ Console ดูคิว (ใช้ได้ทุกหน้า)

```js
const u = JSON.parse(sessionStorage.getItem('pos_user'));
const r = indexedDB.open('pwa-pos');
r.onsuccess = () => {
  const q = r.result.transaction('outbox').objectStore('outbox').getAll();
  q.onsuccess = () => console.table(q.result.map(e => ({
    seq: e.seq, kind: e.kind, bill: e.orderId.slice(0, 8), status: e.status,
    attempts: e.attempts, error: e.lastError, mine: e.userId === u?.sub,
  })));
};
```

### 1.5 ข้อมูลตั้งต้น

- login ด้วย owner · เปิดกะแล้ว · มีโต๊ะว่าง ≥ 3 โต๊ะ · มีเมนูขายได้ ≥ 2 เมนู
- **ก่อนทุกชุดทดสอบ**: ตอนออนไลน์ เปิดหน้าโต๊ะ → หน้า POS (กดโต๊ะไหนก็ได้) → หน้าปิดกะ อย่างละ 1 ครั้ง
  เพื่อให้มี snapshot ครบ 3 ชนิด (`tables`, `menu`, `currentShift`)
  **ลืมข้อนี้ = เมนู/โต๊ะไม่ขึ้นตอนออฟไลน์** (ตั้งใจ — ไม่เคยโหลดก็ไม่มีอะไรให้แสดง)

## 3. สคริปต์เดโม 5 นาที (ซ้อมด้วย preview)

1. **เตรียม** (ก่อนกรรมการมา): build + preview · login · เปิดโต๊ะ / POS / ปิดกะ อย่างละครั้ง · เปิด KDS ไว้อีกแท็บ · ล้างคิวว่าง
2. "ร้านเน็ตหลุด" → ปิด backend → ชี้ป้าย "ติดต่อเซิร์ฟเวอร์ไม่ได้" + แถบข้อมูล ณ เวลา
3. F5 → แอปยังเปิดได้ (service worker)
4. หน้า dev หย่อนบิลโต๊ะ A5 → ป้าย "รอส่ง 1 บิล" → เปิดรายการให้ดู → กลับหน้าโต๊ะ A5 มีลูกค้า
5. ลอง logout → บอกเหตุผลว่าทำไมห้าม (ของจะหาย)
6. เปิด backend → ไม่ต้องกดอะไร → ป้ายหาย → แท็บ KDS มีรายการขึ้น
7. (ถ้ามีเวลา) T9.1 กดรัว → DB ไม่เบิ้ล → อธิบาย UUID + `ON CONFLICT DO NOTHING`

> ข้อ 4 ใช้หน้า dev เพราะหน้า POS ยังไม่ได้ต่อ outbox — ถ้ากรรมการถามให้ตอบตรง ๆ ว่าเป็นงานถัดไป
> หน้า dev มีเฉพาะ `npm run dev` — **preview ไม่มีหน้านี้** (`import.meta.env.DEV`) ถ้าจะเดโมด้วย preview ต้องต่อ MainPOS ให้เสร็จก่อน หรือเดโมข้อ 4 ด้วย dev
